;############################################################
;# 概要
;############################################################
;
; メニューのテキストは 2 系統:
;  (1) 8X8 フォント (BG1, 4BPP) ... 固定文字列 ("MENU", "ゲームスタート" など), ユニット番号と名前
;      1 文字 = タイルマップ 1 エントリ. 文字コード = タイル番号 (JIS X0201 半角カナ + ASCII)
;      濁点 ($DE)/半濁点 ($DF) は独立した 1 文字 ("ケ" + "゛" のように 2 マス)
;  (2) 12X12 フォント (BG3, 2BPP) ... 地名 ("カーディック城") 等. 会話と同じエンジン ($C0F13F/$C0F15F)
;      ($2CF1 = $2001+$145 のメッセージ, $4142 = $2800, $2CF7 = $2C00, $2CF5 = $0210)
;
; 画面構築の流れ ($C0C782):
;  $C0E9A7  PPU 設定: BGMODE $09 (MODE 1, BG3 優先), BG1 マップ $7400, BG2 マップ $7C00, BG3 マップ $2800,
;           BG1/BG2 キャラ $0000, BG3 キャラ $6000
;  $C0EA2B  パレット DMA ($C67000 -> CGRAM $00, $C67200 -> CGRAM $80)
;  $C0EA9E  フォント DMA: $CFA800 -> VRAM $0000 ($2800 バイト, 8X8 フォント + 枠),
;                         $CF9000 -> VRAM $6000 ($400 バイト, BG3)
;  $C0D4E4/$C0D4A7  BG3 / BG2 タイルマップ消去
;  $C1079C  影 $7E41EB をレンガ背景 ($41D6 = $185D) で埋める, $4142 = $7400 (BG1)
;  $C10746  ウィンドウ ID ごとに: 定義表 $C10E76 -> 枠 ($C10CB8) + 文字列 ($C10D54) を影に描画
;           ($34 PAUSE 用, $18 選択枠, $23 ステータス, $01 "MENU")
;  $C0DF43  ユニット一覧: 番号 ($C0EC75) + 名前 ($C0EBD7 -> $C0EC09) を影に直接書込
;  $C0E0B3  選択中の行をパレット 0 に
;  $C0EB4E  地名を 12X12 エンジンで BG3 に
;  $C10E3A  影 $7E41EB ($800 バイト) -> VRAM $7400 を DMA (強制ブランク中)
;  $C1092F  メニュー選択ループ: カーソル点滅 ($C10B43, VRAM 直接書込), パッド ($C0FEE4)
;
; 文字列形式 ($C10D54, ウィンドウ定義 +4 から):
;  $00        終了 (以降の行は空白)
;  $01        改行 (影 +$40 バイト = 1 行)
;  $5C X      エスケープ: X & $0F = 0 かなバイアス 0 (カタカナ), 1 バイアス -$40 (ひらがな),
;             2 全文字 +$80, 3-9 パレット ($41DA = (X-3)*$400)
;  その他     タイル = コード (+バイアス: $A6-$DD かつ $B0 以外のみ) & $1FF | $41DA | $41DC
;  -> $A6-$DD のカタカナを $66-$9D にずらすとひらがなタイルになる
;
; 名前文字列 ($C0EC09, $CF0000 + ポインタ):
;  $00 終了, $68 以降ひらがな (-$40), $6B 以降カタカナ, その他は同じ変換. 属性 = $2029
;
; RAM ($7E):
;  $4142 タイルマップ VRAM アドレス   $4144 ウィンドウ ID       $4146 位置 (下位 = 列, 上位 = 行)
;  $4148 大きさ (下位 = 幅, 上位 = 高さ)  $414A 文字列アドレス ($C10E76 基点)
;  $414C/$4150/$4152 選択肢表 / 無効ボタン   $414E カーソル種類   $414F 選択肢数   $4154 選択肢表アドレス
;  $4156,X ウィンドウ毎のカーソル位置   $41D6 背景タイル   $41D8 かなバイアス   $41DA パレット
;  $41DC 優先度ビット   $41DE カーソル点滅カウンタ   $41E0-$41E7 カーソルタイル ($C10842 から)
;  $41EB-$49EA タイルマップ影 (32X32)

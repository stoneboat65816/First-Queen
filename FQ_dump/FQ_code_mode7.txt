;############################################################
;# 概要
;############################################################
;
; MODE 7 は BG が 1 枚 (回転・拡大用) のみで文字用 BG が無いため, 会話テキストを 16X16 スプライトで描く.
; 文字のデコード ($C0F585, 制御コード, 辞書) と速度/ボタン処理 ($C0FB3A, $C0FACD) は通常の会話と共通
; (FQ_CODE.TXT 参照). 違うのは描画先だけ:
;
;  $C0EE96  入口 (枠なし版): $EEA3 初期化 -> $EF1D -> $F033 ページループ -> $EF48 終了処理
;  $C0EF1D  $2D0D = $4000 (スプライト用 VRAM), $2CFB BIT7=0 ならスプライト全消去 + $2CF7 = 0
;  $C0F033  4 行表示. ページが一杯なら $F0B9 で全スプライトを 16 ドット上へ (最上行は消す) して 1 行追加
;   $C0F3D8  1 行 = 16 文字. 文字毎に:
;     $C0F585  デコード (A = グリフ番号)
;     $C0F9C1  縁取りグリフ作成:
;       $C0FA35  フォント $CFD000 (12X12 1BPP) を 16X16 の作業領域 $7E2D24- へ (右へ 2 ドット)
;       $C0FA5B-$FAA0  上下左右に 1 ドットずらして OR -> 縁 ($7E2D42-)
;       $C0FAB5  縁 = 縁 AND NOT 文字
;       -> 4BPP スプライト 4 タイル ($7E2D60-$2DDF) に並べ替え: プレーン 0 = 文字, プレーン 2 = 縁
;          (色 1 = 文字, 色 4 = 縁, 色 5 = 両方)
;     $C0F242  OAM 影 $7E36EC に 1 エントリ書込, 1 フレーム待ち,
;              グリフ DMA ($C0F765: 上 2 タイル $40 バイト -> $2D0D, 下 2 タイル -> $2D0D+$100),
;              OAM DMA ($C0FD9B: $7E36EC -> OAM, $220 バイト), 速度ウェイト ($C0FB3A)
;   $C0F47D  行末コード確認
;  $C0EF48  $2CFB BIT7=0 ならスプライト全消去して OAM 転送
;
; スプライトの配置 ($C0F242):
;  OAM 番号   = 行 ($2D1B & $FF) * 16 + 列 ($2D1D)          (OAM 影 $36EC + 番号*4)
;  X 座標     = $2CF5 + 列 * 14                             (12 ドット文字 + 縁 = 14 ドット間隔)
;  Y 座標     = $2CF6 + 表示行 ($2D1C) * 16
;  タイル     = 16X16 スプライト形式: n = (行 & 7) * 16 + 列 -> (n & $F8) * 4 + (n & 7) * 2
;  属性       = $3400 | $2CF7 (優先度 3, パレット 2)
;  VRAM       = $4000 + (行 & 7) * $400 + 列 * $20 (16 列を超えると +$100). 8 行分を循環使用
;
; RAM ($7E): 会話と共通 ($2CF1 メッセージ ID, $2CF5 位置 X, $2CF6 位置 Y, $2CF7 属性, $2CFB/$2CFC フラグ,
;  $2D03 テキストポインタ, $2D0D VRAM アドレス, $2D1B 行番号, $2D1C 表示行, $2D1D 列) に加えて:
;  $7E2D20-$2D3F  文字レイヤ (16 行 X 2 バイト)    $7E2D40-$2D5F  縁レイヤ
;  $7E2D60-$2DDF  4BPP スプライト 4 タイル        $7E36EC-$390B  OAM 影 (128 エントリ + 上位 $20 バイト)
;
; 呼出元: $C09E75, $C09EAD, $C0A419, $C0BBAB ($2CF1/$2CF5/$2CF7/$2CFB を設定してから JSL $C0EE96)

;============================================================
; 呼出例 ($2CF5 = $4816, $2CFB = $13) (トレース範囲外)
;============================================================

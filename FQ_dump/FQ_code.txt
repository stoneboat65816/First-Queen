; 主な流れ (1 メッセージ):
;  $C00B5E  イベントインタプリタ: $80 未満 -> オペコード (テーブル $C00BCE), ワード $A000-$BFFF -> メッセージ

;    $EEA3     状態初期化, $2D03 = ポインタテーブル $C12A00 + ID*2 のテキスト位置

;    $EF74     ページ表示: 1 ページ 3 行
;      $F0E7     1 行表示 ($F2BC), 行末で VRAM を次の行へ
